# 예상·실행·비교

실행 전에 각 질문의 답을 한 줄씩 적어 두고, 실행 결과의 `PASS` 줄과 비교하세요.

1. 성공하는 Saga 하나에서 오케스트레이션과 코레오그래피는 각각 Kafka 메시지를 몇 개 보낼까요? 두 수가 다르다면 차이는 어디서 생길까요?
2. 글이 없어 잠금이 실패하면, 그리고 AI 생성이 실패하면 각각 무엇을 어떤 순서로 되돌릴까요? 코레오그래피에서 "예약을 해제하라"고 정하는 서비스는 누구일까요?
3. AI 서비스의 소비를 멈추고 Saga 5개를 시작합니다. 오케스트레이션에서는 어느 DB의 어떤 값이 "5개가 생성 단계에서 멈췄다"를 알려 줄까요? 코레오그래피에서 요청을 받은 Content의 DB만 보면 무엇까지 알 수 있을까요?
4. 성공·잠금 실패·생성 실패·한도 거절이 섞인 60개를 동시에 시작합니다. 두 방식의 최종 상태 분포는 같을까요? 메시지 수는 각각 몇 개일까요? (힌트: 실험 1·2의 경로별 메시지 수)
5. 각 서비스가 처리하는 메시지 가운데 다른 서비스가 정의한 종류는 몇 개일까요? 가장 많은 서비스는 각 방식에서 누구일까요?
6. 생성과 게시 사이에 검수 단계를 넣습니다. 기존 서비스 가운데 구독 목록이 바뀌는 곳은 각 방식에서 어디일까요? 검수에서 떨어진 요약의 토큰은 해제할까요, 확정할까요?
