# 예상·실행·비교

실행 전에 각 질문의 답을 한 줄씩 적어 두고, 실행 결과의 `PASS` 줄과 비교하세요.

1. 오케스트레이터가 상태를 GENERATING으로 커밋한 직후 죽습니다. 같은 DB·같은 소비 그룹으로 다시 띄우면, 명령을 Outbox에 쓰는 경우와 커밋한 뒤 바로 보내는 경우에 Saga는 각각 어떻게 될까요? 다시 받은 `PostLocked`는 어디서 걸러질까요?
2. AI가 멈춘 동안 시한이 없으면, 1초 뒤 같은 글에 시작한 Saga는 어떻게 될까요?
3. 0.5초 시한으로 보상한 뒤 AI가 돌아와 밀린 생성 요청을 처리합니다. 사용량(used)과 AI가 실제로 쓴 토큰은 맞을까요? 늦은 결과를 사용량으로 기록하면?
4. 요약을 게시한 뒤 Usage가 사용량을 확정했지만 응답이 사라졌습니다. 오케스트레이터가 기다리기만 하면, 다시 보내면, 다시 보냈는데 Usage에 "아직 예약 중일 때만" 조건이 없으면, 보상하면 각각 어떻게 될까요?
