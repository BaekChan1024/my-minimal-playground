# 예상·실행·비교

실행 전에 각 질문의 답을 한 줄씩 적어 두고, 실행 결과의 `PASS` 줄과 비교하세요.

1. 작업 30개, 공급자가 2.5초 동안 503입니다. 재시도하지 않으면, 재시도만 하면(최대 3번, 0.2·0.4·0.8초 근처), 재시도에 Circuit Breaker를 더하면 각각 몇 개가 끝나고 장애 중 공급자는 몇 번 불릴까요?
2. 공급자가 처리하고 비용을 매긴 뒤 응답을 잃습니다. 시간 초과·끊김을 재시도하지 않으면, 재시도하면, 재시도하되 멱등키를 실으면 각각 비용은 몇 번 매겨지고 몇 개가 끝날까요?
3. 실패는 없고 호출이 1.2초씩 걸립니다. 느린 호출 규칙을 Resilience4j 기본값으로 둔 차단기는 열릴까요? 6개를 끝내는 데 걸리는 시간은 어떻게 달라질까요?
4. 자동 요약 20개가 먼저 들어오고 저자 요청이 0.1초 뒤에 옵니다. 스레드 1개, 2개, 2개 중 자동 요약은 1개까지일 때 저자는 얼마나 기다릴까요? 마지막 경우 자동 요약은 무엇을 내줄까요?

## 바꿔 보기

- `outage()`의 장애 시간 2500을 600으로 줄이면(`provider.elapsedMs() + 2500`) "재시도만" 변형의 결과가 어떻게 달라질까요? 판정이 어디서 멈추는지 확인한 뒤 되돌리세요.
