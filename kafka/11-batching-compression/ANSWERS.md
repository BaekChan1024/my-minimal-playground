# 해설

1. 다른 전송자가 없는 실습에서 다음 send 자체를 기다리므로 입력을 충분히 모으지 못합니다.
2. 비동기로 빠르게 등록하면 linger=0에서도 전송 사이 레코드가 모입니다. 실제 batch-size-avg를 비교하세요.
3. 관측한 gzip은 바이트 비율을 줄였지만 같은 linger의 none보다 전체 완료 시간이 짧지는 않았습니다. 반복 문자열에 유리한 실험입니다.
4. 지연은 각 send직전→callback, 처리량은600건 전체 완료 구간, Producer 지표는 워밍업 포함640건입니다. p99는 nearest-rank이며 Consumer 업무 완료 시간이 아닙니다.
5. RF1·단일파티션·같은 머신·짧은 워밍업·반복데이터·3회 비교입니다. 장기 부하, CPU·패킷·디스크, 다른 codec, 장애는 측정하지 않았습니다.
