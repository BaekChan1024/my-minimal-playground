# 실행 전에 예상하기

1. 이관 시 글은 ID 1, 2입니다. 새 서비스에서 1을 수정하고 2를 삭제한 뒤 3을 작성했습니다. 원본 DB와 새 DB의 글 수가 같으면 원본을 재사용해도 될까요?
2. 최신 데이터의 `content`를 옛 `body`로 옮기면 충분할까요? 옛 서비스가 모르는 본문 형식도 받아들여야 할까요?
3. ID 1, 3을 명시해서 빈 테이블에 넣었습니다. 이후 ID를 지정하지 않고 INSERT하면 어떤 번호가 나올까요?
4. DB 행을 모두 비교했습니다. 옛 첨부 파일 백업을 연결해도 현재 글이 요구하는 파일을 읽을 수 있을까요? 파일이 존재하기만 하면 충분할까요?
