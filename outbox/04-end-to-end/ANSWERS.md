# 실행 후 해설

1. 0/0. 같은 연결의 트랜잭션 전체가 롤백됩니다.
2. Kafka=0, Inbox=0. 글·Outbox 커밋은 전달 완료가 아닙니다.
3. Kafka=2, Inbox=1, projection=1. 같은 E101을 두 번 보내고 소비자는 한 번 적용합니다.
4. Inbox=0, projection=0, committed=0. 소비자 재생성 후 정상 반영하여 committed=1입니다.
5. Kafka=1 그대로, E101 재수신은 DUPLICATE입니다. DB 결과도 1건 그대로입니다.

조건 변경 해설: offset을 1로 커밋했다면 새 소비자는 0을 재수신하지 않습니다. 이 토픽에 추가 이벤트가 없으므로 next()가 제한 시간 뒤 실패하는 것이 바뀐 전제에 맞는 결과입니다. 소비자 재생성은 정상 종료·재개이며 강제 프로세스 장애를 재현한 것은 아닙니다.
