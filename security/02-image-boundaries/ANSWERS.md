2. gate가 거부합니다. 선언 MIME과 감지한 PNG 형식이 맞지 않습니다.
3. 사라지지 않습니다. XML 문법·root 검사와 활성 콘텐츠 제거는 다른 정책입니다.
4. 확인한 브라우저에서는 nosniff만 붙인 문서의 스크립트가 실행됐습니다. 응답 CSP가 붙은 문서와 img 문맥에서는 문구가 바뀌지 않았습니다. CSP 구성 전체의 효과를 관측했으며 sandbox 단독 효과를 분리 측정한 것은 아닙니다.
5. SHA-256은 비교 대상 바이트의 일치 근거입니다. 포맷·표시·안전성은 별도 검사입니다.
