2. [2,1]. 3은 DB에 남아 있지만 건너뜁니다. 존재 여부도 assert합니다.

4. 가능합니다. 값을 cursor에 보관하고 경계 행을 DB에서 재조회하지 않습니다.
5. 날짜 단독은 [3,2], 복합 키는 [4,3]. ID tie-breaker를 cursor/조건에도 넣어야 합니다.
6. 아니요. 비NULL 경계에서는 OR published_at IS NULL을 더하고, NULL 경계에서는 published_at IS NULL AND id<lastId를 사용합니다. [6,5]→[4,3]→[2,1]→빈 목록을 검증합니다.
